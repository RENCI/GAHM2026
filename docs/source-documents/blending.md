# GAHM2024 and Gridded Meteorology Blending

Rick Luettich 1/25/2026

This document provides an overview of the blending of GAHM2024 and gridded meteorological data, such as generated by ERA5 as contained in blend_GAHM2024a.m.

Step 1: Input and process a storm track

- can be read in ATCF or fort.22 format (read by read_ATCF_fort22.m) or in IBTrACS format (read by read_IBTrACS.m)

- find the starting line (ATCF_startline) and ending line (ATCF_endline) to be used

> Step 2: Input and process

- for env.type =1 or 2: use default, for env.type=3: get from env data structure

- Populate the VEnv_10_10, VHur_10_10, PscaleEnv matrices.

> Step 3: work through the desired time range itime = 1:nBTtime. Work with ATCF_line_t2 and ATCF_line_t1 and associated GAHM fields. Interpolate in time between ATCF values to sync with the desired output / gridded times.

- \_t1 values = \_t2 values (from prev timestep)

- GAHM2024_prep.m

- GAHM2024_consistency.m

- GAHM_t2=GAHM2024v3e.m or GAHM_t2=GAHM2024v4a.m

- For gridded output:

  - GAHM_VPrad_t2.m - Compute radial profiles of vortex velocity and pressure (VVel_VPrad_t2, VPress_VPrad_t2) at specified r, theta values

- For station output

  - ???

- Compute the time interpolating factors tfac2, tfac1 for the output time

- Compute the eye position at the output time (LatNS, LonEW)

- For gridded output:

  - Compute the time interpolated vortex fields on the radial grids (VVel_VPrad_10_10, VSpeed_VPrad_10_10, VPress_VPrad).

  - Compute the environmental field & hurricane field on radial grid. If env.type =1 or 2, this is determined from the storm movement in the track file. If env.type=3, this must correspond to a time in the VEnv_10_10 file (VEnvreg2radial.m).

  - Compute the taper function on the radial grid (radial_taper.m).

  - Apply taper function to vortex fields and to hurricane field (note this is subtracted from the original hurricane fields to achieve inverse taper).

- For station output

  - ???

Step 4: generate output for each time snap

- For gridded output:

  - generate the output grid

  - interpolate the tapered radial GAHM vortex field to the output grid (radial2regular.m)

  - compute and apply the Wind Adjustment Factor due to land roughness

  - for env=3, interpolate the tapered radial hurricane field to the output grid (radial2regular.m)

  - for env=1,2 interpolate the Environmental field from the radial grid to the regular output gird

  - for env=3, interpolate the Environmental field, hurricane field and masks from the regular input grid to the regular output grid

  - blended output = tapered, WAF, GAHM vortex field + original hurricane field + Environmental field -- tapered hurricane field.

Step 1: separate Original Wind and Pressure fields into Environmental fields and Vortex fields.

Step 2: use the Environmental fields (might inverse scale from Zo=0.03m (ERA5) to zo=0.001m (multiply by 1.247) to compute Environmental Wind field for determining GAHM2024 parameters)

Step 3: compute GAHM2024 winds, compute & apply WAF to GAHM winds

Step 4: blend WAF\*GAHM winds & pressure with Vortex fields

Step 5: add in Environmental fields
