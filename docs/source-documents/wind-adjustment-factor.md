# Computation of the Wind Adjustment Factor

Rick Luettich 1/25/2026

This document provides an overview of the computation of the Wind Adjustment Factor (WAF) either at specified points or to create gridded WAF factors for varying wind angles

In each case the required Matlab scripts, inputs and outputs are described.
